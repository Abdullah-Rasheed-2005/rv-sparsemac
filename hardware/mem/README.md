# Memory files

Generated by `python3 software/export_int8.py` (dense files) and
`python3 software/export_sparse.py` (sparse files). Do not edit by hand.

| File | Content | Format |
|---|---|---|
| `fc1_weights.hex` | fc1 weights, 64 x 784, one neuron after another | 2 hex digits per line (int8) |
| `fc1_bias.hex` | fc1 bias, 64 values | 8 hex digits per line (int32) |
| `fc2_weights.hex` | fc2 weights, 10 x 64 | 2 hex digits per line (int8) |
| `fc2_bias.hex` | fc2 bias, 10 values | 8 hex digits per line (int32) |
| `test_images.hex` | first 100 test images, 784 pixels each | 2 hex digits per line (uint8) |
| `test_labels.txt` | true digit of each image | one number per line |
| `golden_logits.txt` | expected fc2 outputs (10 numbers per image) | text |
| `golden_pred.txt` | expected predicted digit | one number per line |
| `params.txt` | sparsity, hidden shift, scales | `key=value` |

Sparse files, written by `export_sparse.py` (only nonzero weights are kept):

| File | Content | Format |
|---|---|---|
| `fc1_nz_idx.hex`, `fc2_nz_idx.hex` | input index of each nonzero weight | 4 hex digits per line |
| `fc1_nz_val.hex`, `fc2_nz_val.hex` | the nonzero weight (int8) | 2 hex digits per line |
| `fc1_nz_ptr.hex`, `fc2_nz_ptr.hex` | neuron n owns list entries `ptr[n]` .. `ptr[n+1]-1` | 4 hex digits per line (65 / 11 lines) |
| `golden_fc1_acc.hex` | raw fc1 dot products, first 10 images, no bias | 8 hex digits per line (int32) |
| `golden_hidden.hex` | hidden values of the first 10 images | 2 hex digits per line |
| `golden_fc2_acc.hex` | raw fc2 dot products, first 10 images, no bias | 8 hex digits per line (int32) |
| `hidden_shift.hex` | hidden right-shift (from `params.txt`) | 2 hex digits, one line |
| `golden_logits.hex` | golden logits of all 100 images, 10 per image | 8 hex digits per line (int32) |

Negative numbers are stored in two's complement.

Load them in Verilog with `$readmemh`.
