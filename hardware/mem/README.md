# Memory files

Generated by `python3 software/export_int8.py`. Do not edit by hand.

| File | Content | Format |
|---|---|---|
| `fc1_weights.hex` | fc1 weights, 64 x 784, one neuron after another | 2 hex digits per line (int8) |
| `fc1_bias.hex` | fc1 bias, 64 values | 8 hex digits per line (int32) |
| `fc2_weights.hex` | fc2 weights, 10 x 64 | 2 hex digits per line (int8) |
| `fc2_bias.hex` | fc2 bias, 10 values | 8 hex digits per line (int32) |
| `test_images.hex` | first 100 test images, 784 pixels each | 2 hex digits per line (uint8) |
| `test_labels.txt` | true digit of each image | one number per line |
| `golden_logits.txt` | expected fc2 outputs (10 numbers per image) | text |
| `golden_pred.txt` | expected predicted digit | one number per line |
| `params.txt` | sparsity, hidden shift, scales | `key=value` |

Negative numbers are stored in two's complement.

Load them in Verilog with `$readmemh`.
